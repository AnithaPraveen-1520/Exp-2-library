# Exp - 2 LIBRARY MANAGEMENT SYSTEM

# AIM:
To design and develop UML diagrams for a Library Management System using different UML diagrams such as Use Case, Activity, Class, Package, Communication, and Sequence diagrams.
# SRS (Procedure):
Step 1: Problem Identification
The main problem is the need for a simple and efficient system to manage library activities such as adding books, searching books, issuing books, and returning books without maintaining everything manually.

Step 2: Requirement Analysis
Identify user needs (student and librarian).
Define functional requirements: login, search book, add book, issue book, return book, update book details, and manage student details.
Define non-functional requirements: security, reliability, speed, accuracy, and usability.

Step 3: System Design
Draw UML diagrams to represent the system:

Use Case Diagram
Class Diagram
Activity Diagram
Sequence Diagram
Communication Diagram
Package Diagram

Design the database with tables for Student, Librarian, Book, and Issue/Return Transaction.
